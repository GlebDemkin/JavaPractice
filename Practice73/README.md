# Reader и Writer

Практическая работа по теме символьных потоков в Java.

`InputStream` и `OutputStream` работают с байтами.

`Reader` и `Writer` работают с символами.

Дополнительная иерархия `Reader` и `Writer` нужна для удобной работы с текстом, потому что текстовые данные зависят от кодировки.

Например, русские символы в UTF-8 могут занимать больше одного байта.

В программе показано:

```text
чтение символов через StringReader
запись символов через StringWriter
разница между количеством символов и количеством байтов
```
