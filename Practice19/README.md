# Типы данных в `switch`

Практическая работа по теме использования конструкции `switch` в Java.

В программе показано, какие типы данных можно использовать в `switch`.

Рассмотрены примеры с типами:

```text
byte
short
char
int
Byte
Short
Character
Integer
String
enum
```

В Java обычный `switch` не поддерживает типы:

```text
boolean
long
float
double
```

Для каждого допустимого типа в программе приведён отдельный пример использования `switch`.

Файл программы:

```text
SwitchTypes.java
```
