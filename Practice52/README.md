# Аннотации в Java

Практическая работа по теме встроенных аннотаций в Java.

В программе показано использование аннотаций:

```text
@Override
@Deprecated
@SuppressWarnings
```

`@Override` используется при переопределении метода родительского класса. Она помогает компилятору проверить, что метод действительно переопределяет существующий метод.

`@Deprecated` помечает устаревший метод, который ещё работает, но не рекомендуется к использованию в новом коде.

`@SuppressWarnings` отключает предупреждения компилятора для выбранного участка кода.

В программе показаны:

```text
переопределение метода
вызов устаревшего метода
подавление предупреждений компилятора
```
