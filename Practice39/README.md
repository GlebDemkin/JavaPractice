# Использование `super`

Практическая работа по теме использования ключевого слова `super` в Java.

В программе показаны три варианта применения `super`:

```text
вызов конструктора суперкласса
обращение к полю суперкласса
вызов метода суперкласса
```

Вызов конструктора суперкласса выполняется так:

```java
super(parentName);
```

Обращение к полю суперкласса:

```java
super.name
```

Вызов метода суперкласса:

```java
super.printInfo();
```

Ключевое слово `super` используется внутри подкласса для обращения к элементам родительского класса.
