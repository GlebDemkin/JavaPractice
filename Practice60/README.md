# Спецификаторы форматирования

Практическая работа по теме класса `Formatter` в Java.

В программе показано использование спецификаторов форматирования:

```text
%s
%d
%f
%c
%b
%%
%n
```

`%s` используется для строк.

`%d` используется для целых чисел.

`%f` используется для чисел с плавающей точкой.

`%c` используется для символов.

`%b` используется для логических значений.

`%%` используется для вывода символа процента.

`%n` используется для переноса строки.

Форматирование выполняется с помощью метода:

```java
formatter.format(...)
```
