# OutputStream и метод write(int)

Практическая работа по теме байтовых потоков вывода в Java.

В программе используется подкласс `OutputStream`:

```text
ByteArrayOutputStream
```

Он позволяет записывать байты во внутренний массив.

Метод `write(int)` записывает один байт в поток вывода.

В программе через `write(int)` записываются символы:

```text
G
l
e
b
```

После записи массив байтов преобразуется обратно в строку.

Файл программы:

```text
OutputStreamWritePractice.java
```
