# Несколько блоков `catch`

Практическая работа по теме обработки нескольких исключений в Java.

В программе показаны две ситуации.

Первая ситуация - несколько исключений обрабатываются одинаково.

Для этого используется один блок `catch` с оператором `|`:

```java
catch (ArithmeticException | NullPointerException e)
```

Так можно делать, если исключения не находятся в одной прямой цепочке наследования.

Вторая ситуация - исключения образуют иерархию:

```text
Ex1
  Ex2
    Ex3
```

При обработке таких исключений блоки `catch` нужно располагать от более конкретного типа к более общему:

```java
catch (Ex3 e)
catch (Ex2 e)
catch (Ex1 e)
```

Если поставить сначала `catch (Ex1 e)`, то остальные блоки станут недостижимыми, потому что `Ex1` перехватит и `Ex2`, и `Ex3`.

Исключения из одной иерархической цепочки нельзя объединять через `|`.
