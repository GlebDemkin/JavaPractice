# Использование `var`

Практическая работа по теме вывода типа в Java.

В программе показано использование ключевого слова `var`. Оно позволяет не указывать тип локальной переменной явно, потому что Java определяет его автоматически по значению справа.

Примеры переменных:

```java
var name = "Глеб";
var age = 19;
var height = 1.83;
var isStudent = true;
var grade = 'A';
```

Также в программе создаётся список чисел:

```java
var numbers = new ArrayList<Integer>();
```

Для вывода типа используется метод `printType()`, который получает значение как `Object` и выводит название его класса через `getClass().getSimpleName()`.
