# Enum с дополнительным методом

Практическая работа по теме перечислений в Java.

В программе создано перечисление `Season`, которое описывает времена года:

```text
WINTER
SPRING
SUMMER
AUTUMN
```

Каждый элемент перечисления содержит:

```text
название сезона
среднюю температуру
```

В enum добавлены методы:

```text
getTitle()
getAverageTemperature()
isWarm()
getDescription()
```

Метод `isWarm()` определяет, является ли сезон тёплым.

Метод `getDescription()` возвращает текстовое описание сезона.

Также в программе показано использование `enum` в конструкции `switch`.
