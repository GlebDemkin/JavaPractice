# Перегрузка методов

Практическая работа по теме перегрузки методов в Java.

В программе создан класс `A`, в котором есть несколько методов с одинаковым названием `printNum()`, но с разными параметрами:

```text
Integer
int
Float
Number
```

Такая ситуация называется перегрузкой методов.

В программе показано, что перегрузка определяется на этапе компиляции.

В цикле `for` переменная имеет тип `Number`, поэтому для всех элементов массива вызывается метод:

```java
printNum(Number n)
```

Хотя реальные объекты внутри массива могут быть `Integer`, `Float` или `Double`.

При отдельных вызовах компилятор видит конкретные типы аргументов, поэтому выбирает разные версии метода:

```java
printNum(Integer)
printNum(int)
printNum(Float)
printNum(Number)
```

Файлы программы:

```text
A.java
Main.java
```
