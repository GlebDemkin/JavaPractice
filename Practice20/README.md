# Отсутствие `break` в `switch`

Практическая работа по теме работы конструкции `switch` в Java.

В программе показано, что происходит, если в одном из блоков `case` отсутствует оператор `break`.

Если `break` не указан, выполнение программы не останавливается на текущем `case` и переходит к следующему `case`.

Такое поведение называется `fall-through`.

В примере переменная `value` равна `2`, поэтому выполнение начинается с `case 2`. Так как после него нет `break`, дополнительно выполняется `case 3`.

В результате итоговое значение переменной `i` становится равным `3`.
