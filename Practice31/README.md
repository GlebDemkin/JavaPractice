# `instanceof` с generic-классами

Практическая работа по теме параметризованных классов в Java.

В программе создан generic-класс `Wrapper<T>`, который хранит значение произвольного типа.

В Java нельзя напрямую проверить параметризованный тип через `instanceof`:

```java
object instanceof Wrapper<Integer>
```

Такая проверка невозможна из-за стирания типов. Во время выполнения Java знает только сам класс `Wrapper`, но не знает, какой тип был указан вместо `T`.

Правильный вариант проверки:

```java
object instanceof Wrapper<?>
```

Также в программе показано, что можно получить значение из `Wrapper` и проверить уже тип самого значения через `instanceof`.
