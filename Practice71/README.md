# InputStream и метод read()

Практическая работа по теме байтовых потоков ввода в Java.

В программе используется подкласс `InputStream`:

```text
ByteArrayInputStream
```

Он позволяет читать данные из массива байтов.

Метод `read()` читает один байт и возвращает его как значение типа `int`.

Если данные закончились, метод `read()` возвращает:

```text
-1
```

В программе строка `"Gleb"` преобразуется в массив байтов, после чего байты считываются по одному.
