# Область видимости переменных

Практическая работа по теме области видимости локальных переменных в Java.

В программе показано, что переменная, объявленная внутри блока `{}`, доступна только внутри этого блока.

В задании рассматривается код:

```java
{
    int b = 2;
}
int a = 1;
int c = a + b;
```

Переменная `c` не получит значение, потому что данный код не скомпилируется. Переменная `b` объявлена внутри отдельного блока и после закрывающей скобки `}` становится недоступной.
