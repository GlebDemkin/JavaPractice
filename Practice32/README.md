# `extends` и `super` в generic-типах

Практическая работа по теме ограничений generic-типов в Java.

В программе показано использование конструкций:

```java
<? extends T>
<? super T>
```

Конструкция `<? extends Number>` означает, что метод может принимать список объектов типа `Number` или его наследников.

Пример:

```java
List<? extends Number>
```

Такой вариант удобно использовать, когда из коллекции нужно читать данные.

Конструкция `<? super Integer>` означает, что метод может принимать список типа `Integer` или одного из его родителей.

Пример:

```java
List<? super Integer>
```

Такой вариант удобно использовать, когда в коллекцию нужно добавлять значения типа `Integer`.

В программе показаны два метода:

```java
sumNumbers(List<? extends Number> numbers)
addIntegers(List<? super Integer> numbers)
```

`extends` используется для чтения чисел из списка.

`super` используется для добавления чисел в список.
