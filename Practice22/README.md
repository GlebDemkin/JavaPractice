# Операторы `break` и `continue`

Практическая работа по теме управления выполнением цикла в Java.

В программе показано использование операторов `break` и `continue` внутри цикла `for`.

Оператор `continue` пропускает текущую итерацию цикла и переходит к следующей.

В программе он используется для пропуска чётных чисел:

```java
if (i % 2 == 0) {
    continue;
}
```

Оператор `break` полностью завершает выполнение цикла.

В программе он используется для выхода из цикла, когда число становится больше `7`:

```java
if (i > 7) {
    break;
}
```
