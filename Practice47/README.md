# Спецификаторы доступа у внутренних классов

Практическая работа по теме внутренних классов в Java.

В программе показаны внутренние классы с разными спецификаторами доступа:

```text
public
protected
default
private
```

Внутренний класс `PublicInner` доступен из других классов.

Внутренний класс `ProtectedInner` доступен внутри пакета и в классах-наследниках.

Внутренний класс `DefaultInner` доступен только внутри текущего пакета.

Внутренний класс `PrivateInner` доступен только внутри внешнего класса `OuterAccess`.

Для создания объекта нестатического внутреннего класса сначала нужен объект внешнего класса:

```java
OuterAccess.PublicInner inner = outer.new PublicInner();
```
