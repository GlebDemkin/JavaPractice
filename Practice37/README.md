# Final-метод

Практическая работа по теме использования модификатора `final` у методов.

В программе создан класс `ParentService`, в котором есть метод:

```java
public final void printVersion()
```

Такой метод можно наследовать и вызывать из объекта дочернего класса, но нельзя переопределять в подклассе.

В классе `ChildService` показан обычный переопределённый метод `printStatus()`.

Попытка переопределить `final`-метод оставлена в комментарии, потому что такой код не скомпилируется.

Файл программы:

```text
FinalMethodPractice.java
```
