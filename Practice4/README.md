# Unicode-символы

Практическая работа по теме использования Unicode-символов в Java.

В программе мы выводим имя в консоль, используя символы в формате Unicode.

Имя записано не обычными русскими буквами, а через Unicode-последовательности:

```text
Г -> \u0413
л -> \u043B
е -> \u0435
б -> \u0431
```

```text
UnicodeNameExample.java
```
