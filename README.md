# Java Practice

Репозиторий предназначен для хранения практических работ по курсу «Язык программирования Java» в Политехе.

Каждая практическая работа находится в отдельной папке:

```text
Practice1/
Practice2/
Practice3/
...
```

В каждой папке размещается одна практика: исходный код и необходимые материалы к заданию. Это правило действует за небольшими разумными исключениями, когда несколько практик по одной теме выгоднее объединить в одну папку.

Ссылки на конкретные папки из этого репозитория будут прикрепляться в системе курса для проверки практических работ.
