# Оператор `+` со строками

Практическая работа по теме использования оператора `+` со строками в Java.

В программе показано, что оператор `+` может соединять строку с переменными разных типов:

```text
object
int
float
boolean
char
```

Для объекта `User` переопределён метод `toString()`, чтобы при выводе объекта отображалось имя пользователя, а не стандартная строка вида `User@4617c264`.

Также в программе показана разница между выражениями:

```java
"Без скобок: " + a + b
```

и:

```java
"Со скобками: " + (a + b)
```

В первом случае числа соединяются как строки, поэтому получается `105`.  
Во втором случае сначала выполняется сложение чисел, поэтому получается `15`.
