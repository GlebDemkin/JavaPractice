# Вызов конструктора через `this()`

Практическая работа по теме использования конструкции `this()` в Java.

`this()` используется для вызова одного конструктора класса из другого конструктора этого же класса.

В программе класс `ConstructorExample` содержит несколько конструкторов:

```text
ConstructorExample()
ConstructorExample(int a)
ConstructorExample(int a, int b)
ConstructorExample(int a, int b, int c)
```

Конструкторы вызывают друг друга по цепочке:

```java
this();
this(a);
this(a, b);
```

Это позволяет не повторять одинаковый код инициализации в каждом конструкторе.

Важно: вызов `this()` должен быть первой строкой конструктора.
