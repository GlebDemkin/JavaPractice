# Аннотация `@Override`

Практическая работа по теме использования аннотации `@Override`.

Аннотация `@Override` показывает, что метод должен переопределять метод родительского класса.

В программе есть классы:

```text
BasePrinter
CorrectPrinter
WrongPrinter
```

Класс `CorrectPrinter` правильно переопределяет метод:

```java
printMessage(String message)
```

Класс `WrongPrinter` содержит метод:

```java
printMessage(int message)
```

Этот метод не переопределяет родительский метод, потому что параметры отличаются.

Если добавить к такому методу аннотацию `@Override`, Java выдаст ошибку компиляции. Это помогает обнаружить ошибку в названии метода, параметрах или типе возвращаемого значения.
