# Текстовые блоки

Практическая работа по теме текстовых блоков в Java.

Три двойные кавычки используются для создания многострочных строк:

```java
String text = """
        Первая строка
        Вторая строка
        Третья строка
        """;
```

Такая запись называется `text block`.

Текстовые блоки нужны, чтобы удобно записывать многострочный текст без постоянного использования `\n` и конкатенации строк.

Их удобно применять для:

```text
HTML
JSON
SQL
многострочных сообщений
```

В программе показано создание обычного многострочного текста и HTML-текста через `"""`.
