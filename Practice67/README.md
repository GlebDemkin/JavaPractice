# `final` в блоке `catch`

Практическая работа по теме использования `final` в параметре блока `catch`.

В конструкции:

```java
try {
    ...
} catch (final Exception e) {
    ...
}
```

ключевое слово `final` означает, что переменной `e` нельзя присвоить новое значение внутри блока `catch`.

Переменная `e` хранит ссылку на пойманный объект исключения. Если она объявлена как `final`, эту ссылку нельзя заменить другой.

Такой код не скомпилируется:

```java
e = new Exception();
```

При этом объект исключения можно использовать обычным образом:

```java
e.getClass().getSimpleName()
e.getMessage()
```

В программе вызывается `ArithmeticException`, после чего исключение перехватывается в блоке `catch`.
