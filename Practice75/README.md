# Чтение файла через Scanner

Практическая работа по теме использования класса `Scanner`.

В программе показано чтение данных из текстового файла.

Для чтения используется класс:

```java
Scanner
```

Файл `input.txt` содержит данные:

```text
Gleb 19 Java
```

Программа считывает из файла:

```text
имя
возраст
язык программирования
```

Метод `next()` читает одно слово.

Метод `nextInt()` читает целое число.

Для автоматического закрытия `Scanner` используется конструкция `try-with-resources`.

Файлы программы:

```text
ScannerFilePractice.java
input.txt
```
