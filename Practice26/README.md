# Перегрузка и переопределение методов

Практическая работа по теме методов в Java.

В программе показаны два механизма:

```text
overloading
override
```

Перегрузка методов используется в классе `Calculator`.

В классе есть несколько методов с одинаковым названием `add()`, но с разными параметрами:

```java
add(int a, int b)
add(double a, double b)
add(int a, int b, int c)
```

Java выбирает нужный метод по количеству и типам аргументов.

Переопределение методов показано на классах:

```text
Animal
Dog
Cat
```

Класс `Animal` содержит метод `makeSound()`.

Классы `Dog` и `Cat` наследуются от `Animal` и переопределяют этот метод через `@Override`.

При вызове метода через переменную типа `Animal` выполняется версия метода из реального класса объекта.
