# Блок `finally`

Практическая работа по теме использования блока `finally` в Java.

В работе рассматриваются три ситуации.

Первая ситуация:

```java
try {
    ...
}
```

Такую конструкцию использовать нельзя. После блока `try` должен быть хотя бы один блок `catch` или блок `finally`.

Вторая ситуация:

```java
try {
    ...
} finally {
    ...
}
```

Такую конструкцию использовать можно. Блок `finally` выполнится после блока `try`.

Третья ситуация:

```java
try {
    ...
} finally {
    ...
} finally {
    ...
}
```

Такую конструкцию использовать нельзя. У одного блока `try` может быть только один блок `finally`.

Если нужно выполнить несколько действий после `try`, их нужно записать внутри одного блока `finally`.
