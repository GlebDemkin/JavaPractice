# Переопределение `equals()`

Практическая работа по теме методов класса `Object`.

В программе создан класс `Student`, для которого переопределён метод `equals()`.

Метод `equals()` используется для сравнения объектов по содержимому.

По умолчанию объекты сравниваются по ссылкам, то есть проверяется, являются ли они одним и тем же объектом в памяти. После переопределения `equals()` можно сравнивать объекты по их полям.

В программе объекты `Student` сравниваются по полям:

```text
name
age
group
```

Также переопределён метод `hashCode()`, потому что если переопределяется `equals()`, нужно переопределять и `hashCode()`.

Реализация `equals()` должна соблюдать основные соглашения:

```text
рефлексивность: объект равен самому себе
симметричность: если a.equals(b) true, то b.equals(a) тоже true
транзитивность: если a.equals(b) и b.equals(c), то a.equals(c)
согласованность: повторные вызовы дают одинаковый результат, если объекты не изменились
сравнение с null всегда возвращает false
```
