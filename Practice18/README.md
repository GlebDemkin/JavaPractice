# Тернарный оператор

Практическая работа по теме условных конструкций в Java.

В программе показано, как заменить конструкцию `if / else if / else` тернарным оператором `? :`.

Исходная логика:

```java
if (a == 1) {
    i = 1;
} else if (a == 2) {
    i = 2;
} else {
    i = 3;
}
```

Запись через тернарный оператор:

```java
int i = (a == 1) ? 1 : (a == 2) ? 2 : 3;
```

Тернарный оператор выбирает значение в зависимости от условия.
