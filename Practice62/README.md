# Форматирование даты и времени

Практическая работа по теме форматирования даты и времени через класс `Formatter`.

В программе используется объект:

```java
LocalDateTime
```

Для форматирования даты и времени используются спецификаторы:

```text
%tH
%tM
%tS
%tY
%tm
%tB
%tA
```

`%tH` выводит час в формате `00-23`.

`%tM` выводит минуты.

`%tS` выводит секунды.

`%tY` выводит год в четырёхзначном формате.

`%tm` выводит месяц числом.

`%tB` выводит полное название месяца.

`%tA` выводит полное название дня недели.

Для вывода названий месяца и дня недели на русском языке используется `Locale`.
