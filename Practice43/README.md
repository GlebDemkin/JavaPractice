# Переопределение методов

Практическая работа по теме переопределения методов в Java.

В программе создан родительский класс `BasicReport` и дочерний класс `PdfReport`.

Класс `PdfReport` переопределяет методы родительского класса:

```text
getTitle()
getPagesCount()
printInfo()
```

Переопределение означает, что в подклассе создаётся метод с таким же названием и такими же параметрами, как в суперклассе.

При вызове метода Java ориентируется на реальный тип объекта. Это называется динамическим связыванием.

Если у переопределяющего метода указан несовместимый тип возвращаемого значения, программа не скомпилируется.

Допустим вариант, когда метод подкласса возвращает более конкретный объектный тип. Например, в родительском классе метод возвращает `Number`, а в дочернем — `Integer`.
