# Основные классы исключений

Практическая работа по теме иерархии исключений в Java.

В программе показаны простые примеры объектов основных классов исключений:

```text
Throwable
Error
Exception
RuntimeException
```

`Throwable` - общий родительский класс для всех объектов, которые можно выбросить через `throw`.

`Error` - серьёзная ошибка среды выполнения. Обычно такие ошибки не обрабатывают в обычной программе.

`Exception` - исключительная ситуация, которую программа может поймать и обработать.

`RuntimeException` - исключение времени выполнения. Обычно связано с ошибками логики программы.

В программе используется метод `printThrowableInfo(Throwable throwable)`. В него можно передать объекты `Error`, `Exception` и `RuntimeException`, потому что все они наследуются от `Throwable`.

Иерархия основных классов:

```text
Object
  Throwable
    Error
    Exception
      RuntimeException
```
