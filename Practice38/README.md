# Final-класс

Практическая работа по теме использования модификатора `final` у классов.

В программе создан класс:

```java
final class SecurityConfig
```

Класс, объявленный как `final`, нельзя использовать как суперкласс.

То есть от него нельзя создать подкласс через `extends`.

Пример запрещённого кода оставлен в комментарии:

```java
class CustomSecurityConfig extends SecurityConfig
```

Если раскомментировать этот код, программа не скомпилируется.

При этом объект `final`-класса создавать можно.

Файл программы:

```text
FinalClassPractice.java
```
