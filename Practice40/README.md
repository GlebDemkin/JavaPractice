# `super` и цепочка наследования

Практическая работа по теме использования `super` в цепочке наследования.

В программе используются классы:

```text
A
B extends A
C extends B
```

Поле `a` и метод `method()` объявлены только в классе `A`.

Класс `B` наследуется от `A`, но не объявляет свои поле `a` и метод `method()`.

Класс `C` наследуется от `B` и вызывает:

```java
super.a
super.method()
```

Ключевое слово `super` обращается к ближайшему суперклассу, то есть к `B`. Но так как в `B` нет собственных поля `a` и метода `method()`, Java использует элементы, унаследованные от класса `A`.
