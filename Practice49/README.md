# Доступ внешнего класса к внутреннему классу

Практическая работа по теме доступа внешнего класса к элементам внутреннего класса.

В программе создан внешний класс `OuterForInnerMembers` и внутренний класс `InnerData`.

Внутренний класс содержит поля и методы с разными спецификаторами доступа:

```text
private
default
protected
public
```

Внешний класс может создавать объект внутреннего класса и обращаться ко всем его полям и методам, включая `private`.

Это работает потому, что внешний и внутренний классы связаны друг с другом.

При этом обычный код вне внешнего класса не может обращаться к `private`-элементам внутреннего класса.

В программе строки с ошибками доступа оставлены в комментариях.

Файл программы:

```text
OuterToInnerAccess.java
```
