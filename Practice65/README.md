# Передача исключений по стеку вызовов

Практическая работа по теме обработки исключений в Java.

В программе показаны два исключения:

```text
ArithmeticException
ArrayIndexOutOfBoundsException
```

Первое исключение возникает при делении на ноль в методе `generateHandledException()`.

Оно не обрабатывается внутри этого метода, поэтому передаётся вверх по стеку вызовов в метод `main()`. В `main()` оно перехватывается блоком `try-catch`, поэтому программа продолжает работу.

Второе исключение возникает при обращении к несуществующему индексу массива в методе `generateUnhandledException()`.

Для него в программе нет обработчика `catch`, поэтому исключение поднимается вверх по стеку вызовов и приводит к аварийному завершению программы.

Также в программе используется блок `finally`, который выполняется после обработки первого исключения.
