# Бесконечные циклы

Практическая работа по теме циклов `while` и `do-while` в Java.

В программе приведены примеры бесконечных циклов:

```text
while
do-while
```

Бесконечный цикл `while` создаётся с помощью условия:

```java
while (true)
```

Бесконечный цикл `do-while` создаётся с помощью условия:

```java
do {
    // код
} while (true);
```

Чтобы программа не выполнялась бесконечно, внутри циклов используется оператор `break`.

Если убрать `break`, оба цикла будут выполняться бесконечно.
