# Ссылки на массивы

Практическая работа по теме массивов в Java.

В программе рассматривается код:

```java
int a1[] = {1, 2, 3, 4, 5};
int a2[] = {6, 7, 8, 9, 10};
a1 = a2;
```

После выполнения `a1 = a2` переменная `a1` начинает ссылаться на тот же массив, что и `a2`.

Старый массив `{1, 2, 3, 4, 5}` больше не доступен через переменную `a1`.

Если после этого изменить элемент массива через `a2`, изменение будет видно и через `a1`, потому что обе переменные ссылаются на один массив.

Для вывода массива используется метод:

```java
Arrays.toString(a1)
```
