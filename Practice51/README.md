# Область видимости интерфейсов

Практическая работа по теме интерфейсов и спецификаторов доступа в Java.

В работе рассматриваются четыре варианта объявления интерфейса.

Интерфейс без спецификатора доступа:

```java
interface Interface {
}
```

Такой интерфейс имеет доступ по умолчанию и доступен только внутри текущего пакета.

Public-интерфейс:

```java
public interface Interface {
}
```

Такой интерфейс доступен из любого класса и любого пакета.

Protected-интерфейс:

```java
protected interface Interface {
}
```

Такой интерфейс нельзя объявить как интерфейс верхнего уровня. `protected` можно использовать только для вложенного интерфейса внутри класса.

Private-интерфейс:

```java
private interface Interface {
}
```

Такой интерфейс также нельзя объявить как интерфейс верхнего уровня. `private` можно использовать только для вложенного интерфейса внутри класса.

В программе показаны все четыре случая. Для `protected` и `private` используются вложенные интерфейсы, потому что на верхнем уровне файла такие спецификаторы недопустимы.
