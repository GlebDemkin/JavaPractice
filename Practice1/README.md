# Принцип подстановки Лисков

В данной программе рассматривается принцип подстановки Лисков.

Принцип подстановки Лисков означает, что объект дочернего класса должен корректно заменять объект родительского класса без нарушения работы программы.

В примере есть базовый класс `CoffeeMachine`, который описывает обычную кофемашину. Она умеет готовить эспрессо и американо.

Класс `SmartCoffeeMachine` наследуется от `CoffeeMachine`. Он сохраняет базовые возможности обычной кофемашины и добавляет новые функции: приготовление капучино и очистку молочной системы.

Метод `makeBasicCoffee(CoffeeMachine machine)` принимает объект типа `CoffeeMachine`. В него можно передать как обычную кофемашину, так и умную кофемашину. Программа продолжает работать корректно, потому что дочерний класс не нарушает поведение родительского класса.
