# Преобразование `int` к `byte`

Практическая работа по теме преобразования типов в Java.

В задании рассматривается код:

```java
int a = 120;
byte b = a + 10;
byte c = (byte)(a + 10);
byte d = a + 1;
```

Переменные `b` и `d` не получат значения, потому что программа не скомпилируется. Выражения `a + 10` и `a + 1` имеют тип `int`, а Java не выполняет автоматическое сужающее преобразование из `int` в `byte`.

Переменная `c` получит значение `-126`, потому что используется явное приведение типа:

```java
byte c = (byte)(a + 10);
```

Выражение `a + 10` даёт `130`, но тип `byte` хранит значения только от `-128` до `127`. Поэтому при приведении происходит переполнение.
