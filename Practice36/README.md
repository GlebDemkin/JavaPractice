# Спецификаторы доступа при наследовании

Практическая работа по теме наследования и спецификаторов доступа в Java.

В программе используются классы:

```text
A
B extends A
C extends B
```

Класс `A` содержит поля и методы с разными спецификаторами доступа:

```text
default
public
protected
private
```

При наследовании спецификаторы доступа не изменяются автоматически.

`public` элементы доступны из любого класса.

`protected` элементы доступны в подклассах и классах того же пакета.

Элементы без спецификатора доступа называются `default`. Они доступны только внутри того же пакета.

`private` элементы доступны только внутри того класса, где они объявлены. Поэтому классы `B` и `C` не могут напрямую обращаться к `a4` и `method4()`.

В программе строки с ошибками доступа оставлены в комментариях.
