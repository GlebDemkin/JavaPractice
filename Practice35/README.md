# Ключевые слова `this` и `super`

Практическая работа по теме наследования в Java.

В программе показано использование ключевых слов `this` и `super` в подклассах.

`this` используется для обращения к текущему объекту. Через `this` можно обращаться к полям и методам текущего класса.

Пример:

```java
this.age = age;
```

`super` используется для обращения к родительскому классу. Через `super` можно вызвать конструктор, метод или поле суперкласса.

Примеры:

```java
super(name);
super.printInfo();
```

В программе есть класс `Parent` и класс `Child`, который наследуется от `Parent`.

Класс `Child` вызывает конструктор родительского класса через `super(name)` и переопределяет метод `printInfo()`.
