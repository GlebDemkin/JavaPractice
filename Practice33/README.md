# Инициализация элементов enum

Практическая работа по теме перечислений в Java.

В программе создано перечисление `TrafficLight`, которое содержит фиксированный набор сигналов светофора:

```text
RED
YELLOW
GREEN
```

Каждый элемент перечисления инициализируется двумя значениями:

```text
название сигнала
длительность сигнала
```

Для этого в enum используются поля и конструктор.

Пример элемента перечисления:

```java
RED("Красный", 30)
```

Метод `values()` используется для перебора всех элементов перечисления.

Файл программы:

```text
TrafficLightExample.java
```
