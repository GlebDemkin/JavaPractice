# Операторы в Java

Практическая работа по теме операторов в Java.

В программе приведены примеры использования основных операторов с базовыми типами данных.

Рассмотрены следующие группы операторов:

```text
арифметические операторы
операторы присваивания
операторы сравнения
логические операторы
побитовые операторы
операторы сдвига
тернарный оператор
инкремент и декремент
операторы со строками
скобки и обращение к элементам массива
```

Для операторов `++` и `--` показаны две формы записи:

```text
префиксная форма
постфиксная форма
```

Также в программе показано использование операторов `+` и `+=` со строками.

Отдельно показано, что оператор `==` у строк сравнивает ссылки на объекты, а не содержимое строк. Для сравнения содержимого используется метод `equals()`.
