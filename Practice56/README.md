# Класс `StringJoiner`

Практическая работа по теме использования класса `StringJoiner`.

`StringJoiner` используется для объединения строк с заданным разделителем.

В программе показаны примеры:

```text
создание StringJoiner с разделителем
создание StringJoiner с префиксом и суффиксом
добавление элементов через add()
задание значения для пустого StringJoiner через setEmptyValue()
объединение двух StringJoiner через merge()
```

Пример создания:

```java
StringJoiner joiner = new StringJoiner(", ");
```
