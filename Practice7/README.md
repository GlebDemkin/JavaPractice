# Арифметические операции с разными типами

Практическая работа по теме автоматического преобразования базовых типов данных в Java.

В программе показано, как Java определяет тип результата при арифметических операциях с переменными разных типов.

Рассмотрены выражения:

```text
byte + short
int + long
long + float
float + double
char + int
```

Для определения типа результата используются перегруженные методы `printType()`. В зависимости от типа переданного значения Java выбирает нужную версию метода.

Также показана особенность Java: в арифметических выражениях типы `byte`, `short` и `char` сначала автоматически преобразуются к `int`.
