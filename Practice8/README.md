# Сужающее преобразование типов

Практическая работа по теме сужающего преобразования базовых типов данных в Java.

В программе показано явное преобразование значений к меньшим типам:

```text
int -> byte
double -> int
long -> short
int -> byte
```

Сужающее преобразование выполняется с помощью указания нужного типа в скобках:

```java
(byte) intValue
(int) doubleValue
(short) longValue
```

В программе показаны разные случаи:

1. `int -> byte` — значение `100` входит в диапазон `byte`, поэтому не изменяется.
2. `double -> int` — дробная часть отбрасывается.
3. `long -> short` — значение не входит в диапазон `short`, поэтому происходит потеря данных.
4. `int -> byte` — показан пример переполнения, так как `130` не входит в диапазон `byte`.
