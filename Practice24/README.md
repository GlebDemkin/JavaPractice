# Методы класса `Arrays`

Практическая работа по теме использования класса `java.util.Arrays`.

В программе показаны основные методы для работы с массивами:

```text
Arrays.toString()
Arrays.sort()
Arrays.binarySearch()
Arrays.equals()
Arrays.compare()
```

Метод `Arrays.toString()` преобразует массив в строку для удобного вывода.

Метод `Arrays.sort()` сортирует массив по возрастанию.

Метод `Arrays.binarySearch()` выполняет бинарный поиск элемента. Перед использованием этого метода массив должен быть отсортирован.

Метод `Arrays.equals()` сравнивает два массива по содержимому.

Метод `Arrays.compare()` сравнивает массивы лексикографически и возвращает число типа `int`.
