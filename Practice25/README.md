# Спецификаторы доступа

Практическая работа по теме спецификаторов доступа в Java.

В программе показана работа четырёх уровней доступа:

```text
private
default
protected
public
```

`private` — элемент доступен только внутри класса, где он объявлен.

`default` — доступ без явного спецификатора. Элемент доступен только классам из того же пакета.

`protected` — элемент доступен классам из того же пакета и классам-наследникам из других пакетов.

`public` — элемент доступен из любого класса и любого пакета.

В программе используются два пакета:

```text
base
other
```

Класс `AccessExample` содержит поля и методы со всеми спецификаторами доступа.

Класс `SamePackageTest` показывает доступ из того же пакета.

Класс `ChildExample` показывает доступ из класса-наследника, который находится в другом пакете.

Класс `Main` запускает программу и показывает, какие элементы доступны из обычного класса другого пакета.

Файлы программы:

```text
AccessExample.java
SamePackageTest.java
ChildExample.java
Main.java
```
