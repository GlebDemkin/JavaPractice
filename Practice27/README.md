# Статические поля и методы

Практическая работа по теме спецификатора `static` в Java.

В программе показаны разные варианты вызова статического метода `printVars()` из класса `A`.

Статический метод принадлежит классу, а не конкретному объекту. Поэтому основной правильный способ вызова:

```java
A.printVars();
```

В программе также показаны другие варианты:

```text
вызов через имя класса
вызов напрямую внутри класса
вызов через объект класса
вызов через ссылку
вызов через имя подкласса
вызов через объект подкласса
вызов через null-ссылку
```

Статические поля `a` и `b` являются общими для всех объектов класса.

Вызов статического метода через объект или ссылку работает, но так писать не рекомендуется. Лучше обращаться к статическому методу через имя класса.
