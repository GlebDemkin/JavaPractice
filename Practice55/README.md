# Методы класса `String`

Практическая работа по теме методов класса `String` в Java.

В программе показана работа десяти методов класса `String`:

```text
length()
trim()
toUpperCase()
toLowerCase()
charAt()
substring()
contains()
indexOf()
replace()
split()
```

Также дополнительно показан метод `equals()` для сравнения содержимого строк.

Объекты класса `String` являются неизменяемыми. Поэтому методы не изменяют исходную строку, а возвращают новое значение.

```text
StringMethodsPractice.java
```
