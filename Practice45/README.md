# Статические методы и полиморфизм

Практическая работа по теме статических методов в Java.

В программе показано, почему динамический полиморфизм не применяется к статическим методам.

Статический метод принадлежит классу, а не объекту. Поэтому он выбирается на этапе компиляции по типу переменной или по имени класса.

В программе есть классы:

```text
StaticParent
StaticChild
```

В обоих классах есть статический метод:

```java
printInfo()
```

Метод `printInfo()` в дочернем классе не переопределяет метод родительского класса, а скрывает его.

Аннотацию `@Override` к статическому методу применять нельзя. Если поставить `@Override`, программа не скомпилируется.

Также в программе есть обычный метод:

```java
printObjectInfo()
```

Он переопределяется в дочернем классе, поэтому для него работает динамический полиморфизм.

Главное отличие:

```text
статический метод выбирается по типу переменной
обычный метод выбирается по реальному типу объекта
```
