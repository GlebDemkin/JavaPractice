# Перегрузка методов

Практическая работа по теме перегрузки методов в Java.

В программе создан класс `OverloadCalculator`, в котором перегружен метод `sum()`.

Перегрузка означает, что в одном классе есть несколько методов с одинаковым названием, но с разными параметрами.

В программе используются версии метода:

```text
sum(int, int)
sum(int, int, int)
sum(double, double)
sum(String, String)
```

Java выбирает нужный метод по количеству и типам переданных аргументов.

Важно: тип возвращаемого значения сам по себе не создаёт перегрузку метода.
