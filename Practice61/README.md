# Метод `flush()`

Практическая работа по теме метода `flush()` у класса `Formatter`.

Метод `flush()` нужен для принудительной отправки накопленных данных из буфера в конечный поток вывода.

В программе `Formatter` записывает данные в файл:

```text
formatter_output.txt
```

После вызова:

```java
formatter.flush();
```

данные принудительно передаются в `FileWriter`.

Метод `close()` обычно тоже выполняет сброс данных, но `flush()` используется тогда, когда нужно отправить данные сразу, не закрывая поток.

Файл программы:

```text
FormatterFlushPractice.java
```
