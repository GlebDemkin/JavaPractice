# Логические блоки

Практическая работа по теме логических и статических блоков в Java.

В программе показан порядок выполнения:

```text
static-блок
логические блоки
инициализация полей
конструктор
```

Статический блок выполняется один раз при первом обращении к классу.

Обычные логические блоки выполняются при каждом создании объекта. Они выполняются в том порядке, в котором расположены в классе.

В данной программе первый логический блок выводит значение `id = 0`, потому что поле `id` ещё не было явно проинициализировано.

После этого выполняется строка:

```java
private int id = 1;
```

Поэтому второй логический блок выводит `id = 1`.

Конструктор вызывается последним и устанавливает значение `id = 100`.

Ожидаемый вывод:

```text
static logic
logic (1) id= 0
logic (2) id= 1
ctor id= 100
```
