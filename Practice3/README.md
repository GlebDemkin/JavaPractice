# Базовые типы данных

Практическая работа по теме базовых типов данных и литералов в Java.

В программе приведены примеры всех восьми базовых типов данных:

```text
byte
short
int
long
float
double
char
boolean
```

Также показаны значения по умолчанию для этих типов. Для этого переменные объявлены как поля класса, поэтому Java автоматически присваивает им нулевые значения.

Файл программы:

```text
TypesExample.java
```
