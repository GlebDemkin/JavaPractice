# IntegerCache

Практическая работа по теме автоупаковки, автораспаковки и класса `IntegerCache`.

В программе сравниваются значения `int` и объекты класса `Integer`.

При сравнении `Integer` и `int` через `==` объект `Integer` автоматически распаковывается в `int`, поэтому сравниваются числовые значения.

При сравнении двух объектов `Integer` через `==` сравниваются ссылки на объекты.

В Java значения `Integer` от `-128` до `127` хранятся в специальном кэше `IntegerCache`. Поэтому для значения `127` переменные `a2` и `b2` ссылаются на один объект.

Для значения `128` создаются разные объекты, поэтому выражение `a1 == b1` возвращает `false`.

Метод `equals()` сравнивает значения объектов, поэтому во всех случаях возвращает `true`.

`IntegerCache` используется для повторного использования часто встречающихся объектов `Integer` и экономии памяти.
