# Доступ внутреннего класса к внешнему классу

Практическая работа по теме доступа внутреннего класса к полям и методам внешнего класса.

В программе создан внешний класс `OuterForInner` и внутренний класс `InnerReader`.

Внешний класс содержит поля и методы с разными спецификаторами доступа:

```text
private
default
protected
public
```

Внутренний класс имеет доступ ко всем полям и методам внешнего класса, включая `private`.

Это возможно потому, что объект нестатического внутреннего класса хранит скрытую ссылку на объект внешнего класса.

В программе внутренний класс обращается к:

```text
privateField
defaultField
protectedField
publicField
privateMethod()
defaultMethod()
protectedMethod()
publicMethod()
```

Файл программы:

```text

```
