# Метод `decode()`

Практическая работа по теме классов-оболочек в Java.

В программе показано использование метода `decode()` для преобразования строк в объекты целочисленных классов-оболочек.

Метод `decode()` понимает разные формы записи чисел:

```text
12      -> десятичное число
012     -> восьмеричное число
0x12    -> шестнадцатеричное число
#12     -> шестнадцатеричное число
-0x12   -> отрицательное шестнадцатеричное число
```

В программе используются методы:

```text
Byte.decode()
Short.decode()
Integer.decode()
Long.decode()
```

Важно: строка `"012"` воспринимается как восьмеричное число, поэтому результат будет `10`, а не `12`.
