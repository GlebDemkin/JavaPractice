# Модификатор `final`

Практическая работа по теме инициализации `final`-полей в Java.

В задании рассматривается поле:

```java
public final int a;
```

Такое поле является константой объекта. Оно не получает значение по умолчанию и должно быть обязательно проинициализировано до завершения создания объекта.

В программе показаны варианты инициализации:

```text
через конструктор с параметром
через конструктор без параметров
через каждый конструктор класса
через нестатический блок инициализации
```

Если в классе несколько конструкторов, поле `final` должно быть проинициализировано в каждом из них.

После создания объекта изменить значение `final`-поля нельзя.
